# Tests manuels gratuits (non automatisables)

## 1. Navigation clavier (Tab / Shift+Tab / Entrée / Espace / Échap / flèches)
- [ ] Tous les éléments interactifs sont atteignables et activables
- [ ] Ordre de tabulation logique
- [ ] Focus toujours visible (RGAA 10.7)
- [ ] Aucun piège clavier (modales, menus, widgets) (RGAA 12.11 / WCAG 2.1.2)
- [ ] Lien d'évitement « Aller au contenu » présent et fonctionnel (RGAA 12.7)
- [ ] Menus et modales fermables avec Échap

## 2. Lecteur d'écran NVDA (gratuit : https://www.nvaccess.org)
- [ ] Titre de page pertinent, langue correcte
- [ ] Structure des titres (NVDA + H) et repères (D) cohérente
- [ ] Images informatives : alternative pertinente ; décoratives ignorées
- [ ] Liens et boutons : intitulés explicites hors contexte (NVDA + F7)
- [ ] Champs de formulaire : label, aide, erreurs annoncés
- [ ] Contenus dynamiques annoncés (aria-live / role=alert)
- [ ] Tableaux de données : en-têtes annoncés

## 3. Contrastes (Colour Contrast Analyser : https://www.tpgi.com/color-contrast-checker/)
- [ ] Texte normal >= 4.5:1 ; grand texte >= 3:1
- [ ] Composants d'interface et focus >= 3:1
- [ ] Information jamais transmise par la couleur seule (RGAA 3.1)

## 4. Autres
- [ ] Zoom 200 % texte seul sans perte de contenu (RGAA 10.4)
- [ ] Reflow à 320 px sans défilement horizontal
- [ ] Vidéos : sous-titres, transcription, audiodescription (thème 4)
- [ ] Extensions gratuites : WAVE, Lighthouse (DevTools), Accessibility Insights
